# Simple To-Do List

A beginner-friendly team project built with **HTML, CSS and JavaScript**. Users can add tasks, mark tasks as completed, delete tasks, and clear all completed tasks.

## How to run
1. Download and extract the ZIP file.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

No installation or database is required.

## Features
- Add a task
- Mark a task as completed
- Delete an individual task
- Clear all completed tasks
- Responsive layout for mobile and desktop

## Team work split (2 members)
- **Member 1 – UI:** Create and maintain `index.html` and `style.css`; check layout on desktop and mobile.
- **Member 2 – Functionality:** Create and maintain `script.js`; test adding, completing, deleting, and clearing tasks.
- **Both members:** Review the code, update this README, and contribute through GitHub branches and pull requests.

## Suggested GitHub workflow
1. One member creates a GitHub repository and adds this project.
2. Both members clone the repository.
3. Each member creates a separate branch for their work.
4. Commit and push changes to their own branch.
5. Open a pull request and review the other member's changes.
6. Merge approved changes into `main`.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Note
This starter version keeps tasks in memory. Refreshing the browser clears the task list. Browser storage can be added as a future improvement.
